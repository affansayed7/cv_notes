Module 04 · Image Segmentation

Image Segmentation.

Detailed, exam-ready notes on partitioning an image into meaningful regions — edge linking & boundary detection, the Hough transform, intensity thresholding & Otsu's method, and region-based segmentation (growing, splitting & merging). Every topic opens with a memorizable definition.

Topic 01

What Is Image Segmentation?

Definition — memorise this

Image segmentation is the process of partitioning a digital image into multiple regions (sets of pixels) that are homogeneous with respect to some property such as intensity, colour, or texture — with the goal of separating meaningful objects or their boundaries from the background.

Segmentation algorithms are based on one of two basic properties of intensity values:

CategoryBased onTechniques
Discontinuity-basedabrupt changes in intensity (edges)point detection, line detection, edge detection (edge linking)
Region-basedsimilarity of intensity within a regionthresholding, region growing, region splitting & merging
Topic 02 · Discontinuity-Based

Edge Linking & Boundary Detection

Definition — memorise this

Edge linking is the process of assembling the individual edge pixels produced by an edge-detection operator into meaningful edges and/or region boundaries, by joining pixels that are separated by gaps caused by noise, non-uniform illumination, or spurious detections.

Edge detection alone rarely gives clean boundaries. Edges detected by various edge-detection operators are not continuous, for the following reasons:

  • Non-uniform illumination — parts of a true edge fall below the detector's response threshold
  • Noise — creates spurious edge pixels and breaks real ones
  • Spurious edge points — false positives scattered across the image

Therefore, edge detection is typically followed by linking algorithms designed to assemble edge pixels into meaningful edges and region boundaries. Two basic approaches exist:

ApproachScope
Local Processingrequires knowledge about edge points in a local region (e.g. a 3×3 neighbourhood)
Global Processingworks with an entire edge image at once, via the Hough Transform
Topic 03

Local Processing

Definition — memorise this

Local processing is an edge-linking method that analyses the pixels in a small neighbourhood (e.g. 3×3) around every edge point, and links a neighbouring pixel to the centre point if it is similar to it in both gradient magnitude and gradient direction.

Input is a binary edge-detected image. For every point (x,y) that is an edge pixel, we analyse each pixel in its small neighbourhood and find neighbours (x',y') that are "similar" to (x,y).

The two similarity criteria

A neighbouring pixel (x',y') is linked to (x,y) if it satisfies both:

1 — Similar gradient magnitude $$ \big|\,\nabla f(x,y) - \nabla f(x',y')\,\big| \le T \qquad (T = \text{a magnitude threshold}) $$
2 — Similar gradient direction $$ \big|\,\alpha(x,y) - \alpha(x',y')\,\big| < A \qquad (A = \text{an angle threshold}) $$

where the strength (magnitude) of the response of the gradient operator is ∇f, and α(x,y) is the direction of the gradient. A neighbour that is similar in both is linked; this joins pixels along genuine edges.

Cost & bookkeeping

This strategy is expensive. A record has to be kept of all linked points — for example, by assigning a different label to every set of linked points.

Local Processing — the algorithm

  1. Compute M(x,y) (gradient magnitude) and α(x,y) (gradient direction) of the input image f(x,y): M(x,y)=|∇f(x,y)|, α(x,y)= direction of the gradient vector.
  2. Form a binary image g:  g(x,y)=1 if M(x,y)>T_M AND α(x,y) ∈ [A−T_A, A+T_A];  g(x,y)=0 otherwise.
  3. Scan rows of g and fill (set to 1) all gaps (sets of 0s) in each row that do not exceed a specified length K.
  4. Rotate g by an angle θ and apply step (3), then rotate the result back by −θ. This detects and fills gaps in any other direction.
Topic 04 · Global Processing

The Hough Transform

Definition — memorise this

The Hough transform is a global edge-linking technique that detects shapes describable in parametric form (such as straight lines) by transforming each edge point in the image space into a curve in a parameter space, and then finding the parameter-space cells that accumulate the most "votes" — each such cell corresponds to a shape present in the image.

It was developed by Richard Duda and Peter Hart in 1972, based on earlier work, as an approach to decide whether sets of pixels lie on curves of a specified shape. Once detected, these curves form the edges or region boundaries of interest.

Why "global" & why not brute force

Often we work in unstructured environments where we only have an edge map and no knowledge about where objects of interest are. All pixels are candidates for linking — checking every possible combination is a brute-force approach that is costly. The Hough transform instead accepts or eliminates pixels based on predefined global properties (do they lie on a common line?), which is far more efficient.

Input to the Hough transform is a binary, thresholded edge image — we have n edge pixels that partially define the boundary of some object, and we wish to find the pixels that make up straight lines.

Topic 05

Hough Transform: The (x,y) ↔ (m,c) Duality

Definition — memorise this

The Hough transform maps between image space and parameter space: a straight line in image space, y = mx + c, is rewritten as c = −xm + y. Under this rewriting a single point in image space becomes a straight line in the (m,c) parameter space, and conversely a point in parameter space corresponds to a line in image space.

Transform the coordinate space (x,y) to the parameter space (m,c). The same equation can be read two ways:

Same equation, two readings $$ \underbrace{y = mx + c}_{\text{slope } m,\ \text{intercept } c \ \ (x,y\text{-space})} \qquad\Longleftrightarrow\qquad \underbrace{c = -xm + y}_{\text{slope } -x,\ \text{intercept } y \ \ (m,c\text{-space})} $$
ObservationStatement
Observation 1A point in (x,y) space ⟷ a line in (m,c) space
Observation 2A line in (x,y) space ⟷ a point in (m,c) space
Observation 3The number of points on the same line in (x,y) space = the number of intersecting lines at one point in (m,c) space
The core idea in one line

Finding a line through many image points becomes finding a point where many parameter-space lines intersect — and counting intersections is something a computer can do efficiently by voting (next topic).

Topic 06

Hough Transform: The Accumulator (Voting)

Definition — memorise this

The accumulator is a discretized 2-D array representing the quantized parameter space (m,c). Each edge point in the image casts a "vote" into every accumulator cell that lies on its parameter-space line; the cell(s) with the highest accumulated vote count identify the parameters of the straight line(s) present in the image.

Given a binary image I in (x,y) space, the "how is it useful" procedure is:

Hough voting algorithm

  1. Step 1 — Discretize & quantize the (m,c) space into cells in the range m_min … m_max, c_min … c_max. Initialise the accumulator array A to all zeros.
  2. Step 2 — For each edge point (xₖ, yₖ), compute cₖ = −xₖ·mₚ + yₖ for all allowed mₚ (from m_min to m_max), and increment the corresponding cell: A(Pₘ, Qc) = A(Pₘ, Qc) + 1.
  3. Step 3 — Identify the cell(s) having the highest vote → A(P,Q). The cell A(P,Q) corresponds to slope mₚ and intercept c_Q — i.e. the detected line. Repeat for the next-highest votes to find additional lines.

Results

Applied to a real image (e.g. a corridor / hallway), the Hough transform successfully extracts the most prominent straight lines: original image → Sobel edge map → the 10 most prominent lines detected by Hough, drawn back onto the scene.

Topic 07

Hough Transform: Normal Form & Advantages

Definition — memorise this

The normal (polar) form of a line, ρ = x·cos θ + y·sin θ, parameterizes a line by its perpendicular distance ρ from the origin and the angle θ of that perpendicular. It is used in the Hough transform because the slope–intercept form (m,c) cannot represent vertical lines (m → ∞).

The limitation of the (m,c) form

There is one limitation with the slope–intercept parameterization: it cannot detect vertical lines, because a vertical line has infinite slope (m → ∞), which cannot be represented in a finite accumulator.

The fix is to use the normal form of the line equation:

Normal (polar) form $$ \rho = x\cos\theta + y\sin\theta $$
  • θ ranges over 0° – 90° (or up to 180°); ρ ranges over ±√(N²+N²) for an N×N image.
  • A point in (x,y) space now gives a sinusoidal curve in the (θ, ρ) parameter space (instead of a straight line).
  • Vertical lines are handled naturally (they simply correspond to θ = 0°).

Advantages of the Hough Transform

  • Conceptually simple.
  • Easy to implement.
  • Handles missing and occluded data gracefully (a partial line still accumulates enough votes).
  • Can be adapted to many types of shapes, not just lines (e.g. circles, ellipses — the "generalized Hough transform").
Topic 08 · Thresholding

Basics of Intensity Thresholding

Definition — memorise this

Intensity thresholding is a region-based segmentation technique that separates objects from the background by selecting one or more intensity threshold values T, and classifying each pixel as object or background according to whether its intensity is above or below T.

Suppose the intensity histogram of an image f(x,y) contains light objects on a dark background. To extract the objects, we select a threshold T that separates the two intensity modes. Any point (x,y) is called an object point if f(x,y) > T; otherwise it is a background point.

Single (global) threshold — output image $$ g(x,y)=\begin{cases} a & \text{if } f(x,y) > T \quad(\text{object})\\ b & \text{if } f(x,y) \le T \quad(\text{background}) \end{cases} $$

Multilevel thresholding

When the histogram has more than two modes (e.g. background + two object types), multilevel thresholding classifies pixels using multiple thresholds T₁, T₂:

Multilevel thresholding $$ g(x,y)=\begin{cases} a & \text{if } f(x,y) > T_2\\ b & \text{if } T_1 < f(x,y) \le T_2\\ c & \text{if } f(x,y) \le T_1 \end{cases} $$
Topic 09

Thresholding Approaches

Definition — memorise this

Global thresholding uses a single threshold value T that is constant over the entire image. Variable thresholding uses a threshold that changes across the image — called local (or regional) thresholding when T depends on a pixel's neighbourhood, and dynamic (or adaptive) thresholding when T also depends on the spatial coordinates (x,y).

ApproachThreshold T depends on
Global thresholdingconstant over the entire image
Variable — local / regionalthe pixels in the neighbourhood of (x,y)
Variable — dynamic / adaptivethe spatial coordinates (x,y) themselves
When can a good global T be found easily?

Thresholding is determined by intensity separation using histograms. A good threshold value T can be easily selected if the intensity distribution has tall, narrow, symmetric, and well-separated peaks (a clean bimodal histogram). When the peaks overlap or are broad, global thresholding struggles and variable thresholding is needed.

Topic 10

The Role of Noise & Illumination in Thresholding

Definition — memorise this

Both image noise and non-uniform illumination degrade the histogram's separability: noise broadens and merges the histogram peaks, while uneven illumination shifts different regions' intensities apart — either effect can turn an easily-thresholdable bimodal histogram into one with no clear valley.

Effect of noise

Consider a simple object on a background with a clean, two-spike histogram. As increasing amounts of Gaussian noise are added, the two sharp spikes broaden into overlapping humps — with heavy noise the valley between them disappears entirely, and no single threshold can separate object from background.

Role of illumination & reflectance

An image is the product of illumination and reflectance: f(x,y) = i(x,y)·r(x,y). Even if the object's reflectance gives a clean bimodal histogram, a non-uniform illumination component i(x,y) multiplies through and smears the histogram, again destroying the valley. This is why correcting or compensating for uneven lighting often precedes thresholding.

Topic 11 · Global Thresholding

Otsu's Method

Definition — memorise this

Otsu's method is an automatic global thresholding technique that determines an optimal threshold by maximizing the between-class variance of the background and foreground pixel classes. It is optimal in the sense of maximizing class separability, and is computed entirely from the image histogram.

Otsu's method converts a grayscale image into a binary image by automatically choosing a threshold T. Suppose dark pixels are background and bright pixels are the object/foreground; we want:

Thresholding rule $$ g(x,y)=\begin{cases} 0, & f(x,y) < T\\ 1, & f(x,y) \ge T \end{cases} $$

The whole problem is: how do we automatically choose T? Otsu's answer: choose the threshold that best separates the image into two classes — background C₀ and foreground C₁ — by maximizing the variance BETWEEN the two classes.

Intuition first

The histogram & notation

Grayscale levels are 0,1,…,L−1 (for an 8-bit image, L=256). Let nᵢ = number of pixels of intensity i, and total pixels N = Σ nᵢ. The normalized histogram is:

Normalized histogram $$ p_i=\frac{n_i}{N}, \qquad \sum_{i=0}^{L-1} p_i = 1 $$

For a candidate threshold T, split pixels into two classes: C₀ = {0,1,…,T} (background) and C₁ = {T+1,…,L−1} (foreground). Then compute four things for every possible T:

① Class probabilities (weights)

Weights — just add histogram probabilities $$ w_0(T)=\sum_{i=0}^{T} p_i \qquad w_1(T)=\sum_{i=T+1}^{L-1} p_i \qquad w_0 + w_1 = 1 $$

② Class means

Means — multiply intensity × probability, then divide by weight $$ \mu_0=\frac{\sum_{i=0}^{T} i\,p_i}{w_0} \qquad \mu_1=\frac{\sum_{i=T+1}^{L-1} i\,p_i}{w_1} $$

③ Between-class variance ⭐ (the key formula)

Between-class variance — memorise this above all $$ \sigma_B^2 = w_0\,w_1\,(\mu_0 - \mu_1)^2 $$

④ Pick the T that maximizes σ_B²

Optimal threshold $$ T^{*} = \arg\max_{T}\ \sigma_B^2(T) $$
Why this formula makes sense

σ_B² = w₀·w₁·(μ₀−μ₁)² has three parts: w₀ (how many pixels are background), w₁ (how many are foreground), and (μ₀−μ₁)² (how far apart their average intensities are). We want meaningful classes whose means are far apart. E.g. μ₀=20, μ₁=100 → difference 80 (great separation) beats μ₀=40, μ₁=60 → difference 20 (poor separation).

Worked Example 1 — a symmetric histogram

An image with 5 intensity levels: counts n = [2, 3, 4, 3, 2] for levels 0–4, so N = 14. Test thresholds T = 1 and T = 2 (avoid thresholds that produce an empty class).

T = 1 → C₀={0,1}, C₁={2,3,4}

w₀ = 5/14 = 0.3571,  w₁ = 9/14 = 0.6429

μ₀ = (0·2 + 1·3)/5 = 3/5 = 0.6

μ₁ = (2·4 + 3·3 + 4·2)/9 = 25/9 = 2.778

σ_B² = (5/14)(9/14)(0.6−2.778)² ≈ 1.089

T = 2 → C₀={0,1,2}, C₁={3,4}

w₀ = 9/14 = 0.6429,  w₁ = 5/14 = 0.3571

μ₀ = (0·2+1·3+2·4)/9 = 11/9 = 1.222

μ₁ = (3·3 + 4·2)/5 = 17/5 = 3.4

σ_B² = (9/14)(5/14)(1.222−3.4)² ≈ 1.089

Note

Both give ≈ 1.089 — because this histogram is symmetric, T=1 and T=2 are equally good. (Real exam histograms are usually asymmetric, giving a unique answer — see Example 2.)

Worked Example 2 — a unique optimal threshold

Levels 0–3 with counts n = [4, 6, 5, 1], so N = 16. Test T = 0, 1, 2. This is exactly how to lay out an exam numerical — build a table:

The maximum σ_B² = 0.575 occurs at T = 1 → the Otsu threshold is 1.

The algorithm to memorise

Otsu's Algorithm

Input: grayscale image with L intensity levels.

  1. Step 1: compute the normalized histogram pᵢ = nᵢ/N.
  2. Step 2: for each possible threshold T = 0,…,L−2, calculate w₀, w₁, then μ₀, μ₁, then σ_B²(T) = w₀·w₁·(μ₀−μ₁)².
  3. Step 3: find T* = arg max σ_B²(T).
  4. Step 4: threshold the image using T*.

Useful shortcuts & relationships

Faster computational form (cumulative moments) $$ \sigma_B^2(T)=\frac{\big[\mu_T\,\omega_0(T)-\mu(T)\big]^2}{\omega_0(T)\,[1-\omega_0(T)]}, \quad\text{where } \omega_0(T)=w_0,\ \mu(T)=\sum_{i=0}^{T} i\,p_i,\ \mu_T=\sum_{i=0}^{L-1} i\,p_i $$
Overall mean = weighted average of the two class means $$ \mu_T = w_0\,\mu_0 + w_1\,\mu_1 $$
Learn the simple form first

For your exam, master σ_B² = w₀·w₁·(μ₀−μ₁)² first — the cumulative-moment form above is just a faster route for large 8-bit histograms.

Theory: variance decomposition (common theory question)

The total variance of an image decomposes into within-class and between-class variance:

Variance decomposition $$ \sigma_T^2 = \sigma_W^2 + \sigma_B^2 $$

Since the total variance σ_T² is fixed for a given image, maximizing σ_B² is exactly equivalent to minimizing σ_W²:

Two equivalent views of Otsu $$ \max\ \sigma_B^2 \iff \min\ \sigma_W^2 $$
What within-class variance means

σ_W² measures how spread-out the pixels are inside each class. A good threshold gives tight classes (e.g. C₀ = {10,11,12,10}, C₁ = {200,202,198,201}) → small σ_W². A bad threshold mixes dark and bright pixels into one class → huge σ_W². So Otsu can be stated two ways: maximize between-class variance OR minimize within-class variance.

Otsu vs manual vs adaptive thresholding

OtsuAdaptive / Local

Manual thresholding just picks a value ("I'll use T=128") with no optimization; Otsu = automatic threshold selection that mathematically finds the best-separating value.

Limitations of Otsu

Otsu assumes the histogram has reasonably separable classes. It may fail or give poor segmentation when: the histogram is not clearly bimodal (a single broad hump with no valley), foreground/background proportions are extremely unbalanced, illumination is non-uniform, or noise significantly distorts the histogram.

Multilevel & edge-improved variants

Multilevel Otsu extends the idea to multiple thresholds by maximizing σ_B² = P₁(m₁−m_G)² + P₂(m₂−m_G)² + P₃(m₃−m_G)² for three classes. Edge-improved global thresholding: doing edge detection first (using the gradient or absolute Laplacian to keep only pixels on/near edges before building the histogram) sharpens the histogram peaks and yields a better threshold.

Exam quick-reference — the 5 formulas + the criterion

pᵢ = nᵢ/N  ·  w₀ = Σᵢ₌₀ᵀ pᵢ  ·  w₁ = 1 − w₀  ·  μₖ = (Σ_{i∈Cₖ} i·pᵢ)/wₖ  ·  σ_B² = w₀·w₁·(μ₀−μ₁)²  ·  criterion: T* = arg max σ_B² (equivalently, min within-class variance).

Topic 12

Variable / Adaptive Thresholding

Definition — memorise this

Variable thresholding computes a threshold at every point (x,y) based on one or more properties (such as the local mean and standard deviation) of the pixels in a neighbourhood S_xy centred at that point, allowing segmentation to succeed even under non-uniform illumination where a single global threshold would fail.

Compute a threshold at every point (x,y) based on properties of the pixels in a neighbourhood S_xy:

  • m_xy = mean of the pixel values in neighbourhood S_xy
  • σ_xy = standard deviation of the pixel values in S_xy

Common forms of variable thresholds based on these local properties:

Local-property thresholds $$ T_{xy}=a\,\sigma_{xy}+b\,m_{xy} \qquad\text{or}\qquad T_{xy}=a\,\sigma_{xy}+b\,m_G $$

where a and b are nonnegative constants and m_G is the global mean. The segmented image is then:

Segmentation with a local threshold $$ g(x,y)=\begin{cases} 1 & \text{if } f(x,y) > T_{xy}\\ 0 & \text{if } f(x,y) \le T_{xy} \end{cases} $$

Variable thresholding based on moving averages

Definition — memorise this

Moving-average thresholding is a variable-thresholding method in which the threshold at each pixel is based on the running (moving) average of intensities computed along a zig-zag raster scan of the image — particularly effective for images corrupted by patterned illumination such as spot shading, and for text.

Using a raster-scan process, let z_{k+1} denote the intensity of the point encountered at step k+1. The moving average (mean intensity) at this new point is:

Moving average update $$ m(k+1)=\frac{1}{n}\sum_{i=k+2-n}^{k+1} z_i = m(k)+\frac{1}{n}\big(z_{k+1}-z_{k-n}\big) $$

where n is the number of points used in computing the average. The threshold at each point is T_xy = c·m_xy (with c a constant), giving g(x,y)=1 if f(x,y)>T_xy, else 0.

Classic example: a page of handwritten text corrupted by spot shading. Global thresholding fails (the shading swamps the ink in dark areas), but moving-average thresholding tracks the local background and recovers the text cleanly.

Topic 13 · Region-Based Segmentation

Region Growing

Definition — memorise this

Region growing is a region-based segmentation procedure that groups pixels or subregions into larger regions based on predefined criteria for growth. It starts from a set of "seed" points and grows regions by appending to each seed those neighbouring pixels that have properties similar to the seed (such as ranges of intensity or colour).

  • The basic approach is to start with a set of seed points.
  • Grow regions by appending to each seed those neighbouring pixels that have predefined properties similar to the seed (e.g. intensity within a range, or similar colour).

Segmentation by region growing — the algorithm

  1. Find all connected components in the seed array S(x,y) and reduce each connected component to one pixel; label all such pixels found as 1, all others 0.
  2. Form an image f_Q such that, at each point (x,y), f_Q(x,y)=1 if the input image satisfies a given predicate Q at those coordinates, and f_Q(x,y)=0 otherwise.
  3. Let g be an image formed by appending to each seed point all the 1-valued points in f_Q that are 8-connected to that seed point.
  4. Label each connected component in g with a different region label (e.g. integers or letters) — this is the segmented image obtained by region growing.
Topic 14

Region Splitting & Merging

Definition — memorise this

Region splitting and merging is a region-based segmentation technique that subdivides an image initially into a set of arbitrary, disjoint regions, then splits any region that fails a homogeneity predicate and merges adjacent regions that together satisfy it — repeating until every region is homogeneous and no further merges are possible.

An alternative to region growing: subdivide an image initially into a set of disjoint regions, then merge and/or split the regions in an attempt to satisfy the conditions of segmentation. The standard structure is the quadtree.

The split-and-merge algorithm

  1. Split into four disjoint quadrants any region Rᵢ for which the homogeneity predicate Q(Rᵢ) = FALSE.
  2. When no further splitting is possible, merge any adjacent regions Rⱼ and Rₖ for which Q(Rⱼ ∪ Rₖ) = TRUE.
  3. Stop when no further splitting or merging is possible.
Growing vs Splitting/Merging — the contrast

Region growing starts small (seeds) and grows outward. Splitting & merging starts with the whole image and repeatedly divides non-uniform regions (top-down) then merges compatible neighbours (bottom-up). Both aim for the same goal: a set of maximal homogeneous regions.

Cram Sheet

All Definitions, In One Place

Every "Definition — memorise this" box from the topics above, gathered here for a final memorization pass before the exam.

1. Image Segmentation

The process of partitioning a digital image into multiple regions that are homogeneous with respect to some property (intensity, colour, texture), to separate meaningful objects or boundaries from the background.

2. Edge Linking

The process of assembling the edge pixels produced by an edge detector into meaningful edges and region boundaries by joining pixels separated by gaps caused by noise, non-uniform illumination, or spurious detections.

3. Local Processing

An edge-linking method that analyses the pixels in a small neighbourhood around every edge point and links a neighbour if it is similar in both gradient magnitude and gradient direction.

4. Hough Transform

A global technique that detects parametric shapes (e.g. lines) by transforming each edge point into a curve in parameter space, then finding the parameter cells with the most votes — each corresponding to a shape in the image.

5. Hough (x,y)↔(m,c) Duality

Rewriting y=mx+c as c=−xm+y makes a point in image space become a line in (m,c) parameter space, and a line in image space become a point in parameter space.

6. Accumulator (Voting)

A discretized 2-D array of the quantized parameter space; each edge point votes into every cell on its parameter curve, and the peak cell identifies the line's parameters.

7. Normal Form of a Line

ρ = x·cosθ + y·sinθ, parameterizing a line by perpendicular distance ρ and angle θ; used in the Hough transform because the (m,c) form cannot represent vertical lines.

8. Intensity Thresholding

A region-based technique that separates objects from background by selecting threshold(s) T and classifying each pixel by whether its intensity is above or below T.

9. Global vs Variable Thresholding

Global uses one constant T over the whole image; variable changes T across the image — local/regional (depends on the neighbourhood) or dynamic/adaptive (also depends on coordinates).

10. Role of Noise & Illumination

Noise broadens and merges histogram peaks; non-uniform illumination shifts region intensities apart — either can destroy the valley needed for thresholding.

11. Otsu's Method

An automatic global thresholding technique that chooses the threshold T maximizing the between-class variance σ_B² = w₀·w₁·(μ₀−μ₁)² — equivalently, minimizing within-class variance (since σ_T² = σ_W² + σ_B² is fixed). Computed entirely from the histogram.

12. Variable / Adaptive Thresholding

Computes a threshold at every point from properties (local mean, std-dev) of the neighbourhood S_xy, succeeding under non-uniform illumination where a global threshold fails.

13. Region Growing

Groups pixels into larger regions by starting from seed points and appending neighbouring pixels whose properties (e.g. intensity range) are similar to the seed.

14. Region Splitting & Merging

Subdivides the image into disjoint regions, splits any region failing a homogeneity predicate (quadtree), and merges adjacent regions that jointly satisfy it, until all regions are homogeneous.
