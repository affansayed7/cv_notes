Module 01

Digital Image Representation

A digital image is a function f(x, y) that has been digitised in both spatial coordinates and brightness. The value of f at a point (x, y) is proportional to the brightness (gray level) at that point.

Put simply: a digital image is a 2-D signal stored as a finite set of digital values called picture elements → pixels, arranged in a 2-D grid.

Remember

Digitise = 2 steps. Coordinates are digitised by sampling; brightness is digitised by quantization. Miss either and it isn't a digital image.

Module 02

Image Sampling & Quantization

Sensor output is a continuous voltage waveform whose amplitude & spatial behaviour track the physical phenomenon being sensed. To make it digital we convert that continuous signal into a digital format in two ways:

StepWhat it digitisesMeaning
Samplingthe coordinate valuesHow many pixels — the grid spacing (spatial digitisation)
Quantizationthe amplitude valuesHow many intensity levels — the bits per sample

Quantization depth = bits per sample:

  • 1 bit/pixel → black & white images
  • 8 bit/pixel → grayscale images
  • 16-bit audio, 24-bit colour images, etc.
One-liner

Sampling → rows & columns. Quantization → gray levels. Together they turn the continuous "hill" into a blocky digital array.

Module 03

The Uniform Quantizer

A uniform quantizer splits the brightness range into equal-width levels. Given input brightness u ∈ [Lmin, Lmax] and a quantizer of B bits:

QuantityExpression
No. of reconstruction levelsL = 2ᴮ
End decision levelsT₁ = Lmin,   T₍ₗ₊₁₎ = Lmax
Step size (level width)q = tₖ − tₖ₋₁ = (Lmax − Lmin) / L

Quantization error (MSE)

For an image of size M×N, with U = non-quantized and U′ = quantized:

Mean Squared Error $$ \text{err} \;=\; \frac{1}{MN}\sum_{m=0}^{M-1}\sum_{n=0}^{N-1}\big(u(m,n)-u'(m,n)\big)^2 $$

Results — more bits, less error

Bits BLevels L = 2ᴮQuantization error (MSE)
B = 1236.2 — heavy false contouring
B = 2415 — visibly smoother
Remember

As B ↑, levels L = 2ᴮ ↑, step q ↓, and MSE ↓. Fewer bits ⇒ coarser levels ⇒ larger error ⇒ false contours in smooth regions.

Module 04

Image Basics & Storage

TermMeaning
Dynamic rangeRatio of the highest to lowest measurable intensity in the image.
Image contrastDifference in intensity between the brightest and darkest regions.
Contrast ratioThe ratio form of the above.
  • An appreciable number of pixels spread over a high dynamic range ⇒ high contrast image.
  • A low dynamic range ⇒ dull, low-contrast (flat) image.

Bits required to store an image

For an image of size M × N with intensity levels 2ᵏ (i.e. k bits per pixel):

Storage size $$ b \;=\; M \times N \times k \quad\text{bits} $$
Exam move

If they say "256 gray levels", read it as 2⁸ ⇒ k = 8 bits/pixel. Then plug into M·N·k.

Module 05

Spatial & Intensity Resolution

ResolutionMeasuresStated as
Spatialsmallest discernible spatial detailline pairs / unit dist., dots (pixels) per unit dist., dpi
Intensitysmallest discernible change in intensity8 bits, 12 bits, 16 bits …

Two artefacts to name

Checkerboard effect

Reduce spatial resolution too much (e.g. 32×32) and pixels become visible blocks — the image looks like a checkerboard.

cause → too few samples

False contouring

Reduce intensity resolution (too few gray levels, e.g. 2–16) and fake edges/rings appear in smooth areas that had fine gradients.

cause → too few gray levels

Don't mix these up

Checkerboard ↔ spatial (samples). False contour ↔ intensity (gray levels). Classic exam trap.

Module 06

Image Interpolation

Interpolation = image resizing (shrinking / zooming). It estimates the best approximation of a pixel's colour & intensity from the values of surrounding pixels.

MethodNeighbours usedResult
Nearest neighbourclosest 1 pixelfastest; blocky
Bilinearclosest 2×2 (4 px), weighted averagesmoother than NN; more processing time
Bicubicclosest 4×4 (16 px), closer pixels weighted highersharpest of the three; good quality/time compromise; standard in editors, printer drivers, in-camera
Remember the numbers

1 → 4 → 16 pixels for Nearest → Bilinear → Bicubic. Bilinear = 2×2, Bicubic = 4×4.

Module 08

Adjacency & Connectivity

Connectivity defines object boundaries and image regions. Two pixels are connected if they are adjacent in some sense — a pixel p is adjacent to q if they are connected.

Two pixels are connected iff (1) they are neighbours (N₄, N₈, or N_D) and (2) their intensities satisfy a similarity set V (the set of gray-level values used to define connectivity).

TypeCondition (p, q with values in V)
4-connectivityq ∈ N₄(p)
8-connectivityq ∈ N₈(p)
m-connectivity
(mixed)		q ∈ N₄(p),  OR
q ∈ N_D(p) AND N₄(p) ∩ N₄(q) has no pixels with values from V
Why m-adjacency exists

8-connectivity can create multiple paths between the same two pixels (ambiguous boundaries). m-connectivity removes these extra paths, giving one clean path.

Module 09

Path, Region & Boundary

Path

A path from p(x, y) to q(s, t) is a sequence of distinct pixels (x₀,y₀), (x₁,y₁), … , (xₙ,yₙ) where (x₀,y₀)=(x,y), (xₙ,yₙ)=(s,t), and consecutive pixels are adjacent for 1 ≤ i ≤ n.

  • n = length of the path.
  • Paths can be 4-, 8- or m-paths depending on the adjacency used.

Worked example · V = {1, 2}, from (1,3) to (3,3)

8-paths (two exist):  (i) (1,3)→(1,2)→(2,2)→(3,3)  ·  (ii) (1,3)→(2,2)→(3,3)

m-path (unique):  (1,3)→(1,2)→(2,2)→(3,3)

Connected component & region

TermDefinition
Connected in SPixels p, q are connected in subset S if a path between them lies entirely in S.
Connected componentFor a pixel p ∈ S, the set of all pixels connected to it in S.
Region RA subset where every pixel is connected to any other pixel in R.
Boundary (border/contour)Pixels in the region that have one or more neighbours outside the region.
Adjacent subsets

Two image subsets S₁, S₂ are adjacent if some pixel in S₁ is adjacent to some pixel in S₂.

Module 10

Labeling of Connected Components

Scan the image left → right, top → bottom. Let p = current pixel, t = upper neighbour, l = left neighbour (already scanned & labelled if they were 1s).

4-connectivity algorithm

  1. If p = 0 → move on.
  2. If p = 1 → examine l and t:
    • both 0 → assign a new label to p.
    • only one is 1 → assign its label to p.
    • both are 1:
      • same label → assign that label to p.
      • different labels → assign one to p and record the two labels as equivalent (they connect through p).
  3. At end of scan, all 1-pixels are labelled. Second pass: assign one unique label per equivalence class. → e.g. {1,2,5} become one, {3,4} become one.
8-connectivity variant

Same idea, but also examine the two upper-diagonal neighbours. If two or more neighbours are 1, assign one label and note the equivalences; resolve them in the second pass.

Module 12

Arithmetic Operations on Images

Carried out pixel by pixel on two same-size images I₁, I₂. Watch for overflow/underflow → handled by clipping or rescaling.

OpFormula (clipped)Use
AddI = min(I₁+I₂, Imax)image averaging → noise reduction
SubtractI = max(I₁−I₂, Imin)basic tool in medical imaging
MultiplyI₁ = I·I₂correct gray-level shading from illumination/sensor non-uniformity; masking (ROI)
DivideI = I₁ / I₂,  I₂ ≠ 0shading correction; remove 0s by adding unity I₃ = I₂ + 1

Division of two comparable images gives small / non-integer outputs, so rescale to the full display range, e.g. [0, 255].

Noise reduction by averaging K images

Noiseless image f(x,y), noise n(x,y) (uncorrelated, zero mean), corrupted g = f + n. Average K noisy frames:

Averaging & its statistics $$ \bar g(x,y)=\frac{1}{K}\sum_{i=1}^{K} g_i(x,y),\qquad E\{\bar g(x,y)\}=f(x,y) $$ $$ \sigma^2_{\bar g(x,y)}=\frac{1}{K}\,\sigma^2_{n(x,y)} $$
The key result

Averaging K frames keeps the true image f but cuts noise variance by 1/K. More frames ⇒ less noise (NGC 3314 galaxy demo: 5 → 100 frames).

Application · Mask-mode radiography (subtraction)

g(x,y) = f(x,y) − h(x,y). Mask h = X-ray before contrast; live f = X-ray after contrast injection. The difference reveals blood vessels (digital subtraction angiography).

Logical Operations on Images

  • Carried out pixel by pixel.
  • Apply only to binary images (arithmetic ops apply to multivalued pixels).
  • Used for masking, feature detection and shape analysis.
OperatorResult
NOT(A)inverts the binary image

One-line distinction

Logical ⇒ binary images. Arithmetic ⇒ multivalued (gray) images.

Module 14

Image Geometry — Affine Transforms

Basic transformations, expressed in the 3-D Cartesian system (x, y, z) using a 3×3 affine matrix A. Types: translation, scaling, rotation, plus concatenation & inverse transforms.

TransformCoordinate equations
Identityx′ = x,  y′ = y
Scaling / Reflection
reflect: set one factor −1		x′ = cₓ·x,  y′ = c_y·y
Rotation (about origin)x′ = x cosθ − y sinθ
y′ = x sinθ + y cosθ
Translationx′ = x + tₓ,  y′ = y + t_y
Shear (vertical)x′ = x + s_v·y,  y′ = y
Shear (horizontal)x′ = x,  y′ = s_h·x + y
Rotation matrix (homogeneous 3×3) $$ A_{rot}=\begin{bmatrix} \cos\theta & -\sin\theta & 0 \\ \sin\theta & \cos\theta & 0 \\ 0 & 0 & 1 \end{bmatrix} \qquad A_{trans}=\begin{bmatrix} 1 & 0 & t_x \\ 0 & 1 & t_y \\ 0 & 0 & 1 \end{bmatrix} $$
Why 3×3?

Homogeneous coordinates let translation (an addition) be written as matrix multiplication, so transforms can be concatenated into one matrix.

Module 15

Distance Measures

Distance between pixels p(x₁,y₁) and q(x₂,y₂) — three standard measures:

The three distances $$ D_e(p,q)=\sqrt{(x_1-x_2)^2+(y_1-y_2)^2}\quad\text{(Euclidean)} $$ $$ D_4(p,q)=|x_1-x_2|+|y_1-y_2|\quad\text{(city-block)} $$ $$ D_8(p,q)=\max\big(|x_1-x_2|,\,|y_1-y_2|\big)\quad\text{(chessboard)} $$

Distance metric — the 4 properties

A distance function D is a metric if:

  1. D(p,q) is well-defined & finite for all p, q.
  2. D(p,q) ≥ 0;  and D(p,q)=0 ⟺ p=q.
  3. Symmetry: D(p,q) = D(q,p).
  4. Triangle inequality: D(p,q) + D(q,t) ≥ D(p,t).
Nickname hook

D₄ = city-block (Manhattan) · D₈ = chessboard (king's move) · Dₑ = straight line. Metric properties: non-negative, identity, symmetric, triangle.
